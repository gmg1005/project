Web Security Lab

OWASP Top 10 보안 취약점을 직접 공격해보면서 배우는 실습실입니다. 힌트는 단계적으로 열리고, 성공하면 취약한 코드와 패치된 코드를 바로 비교해서 보여줍니다.

📖 사용법 (처음이시라면 펼쳐보세요)
  • 아래 카드를 눌러 원하는 취약점 실습으로 이동하세요.
  • 각 실습은 기초 이론 → 레벨별 실습(힌트 제공) → 종합 Challenge(힌트 없음) → 방어자 퀴즈 → 정리 순서로 구성되어 있어요.
  • 레벨은 순서대로 진행하는 걸 권장하지만, 이미 아는 내용이 있다면 자유롭게 건너뛰어도 됩니다.
  • 모든 실습은 브라우저 안에서만 동작하는 시뮬레이션이라 실제 서버나 DB에 영향을 주지 않습니다.
● 실습 가능

SQL Injection

로그인 우회부터 필터 우회, Prepared Statement로 패치된 버전까지 — 4개 레벨 + 종합 Challenge + 방어자 퀴즈

 ● 실습 가능

Cross-Site Scripting (XSS)

Reflected / Stored XSS부터 필터 우회, HTML 이스케이프로 패치된 버전까지 — 4개 레벨 + 종합 Challenge + 방어자 퀴즈

 ● 실습 가능

Broken Access Control (IDOR)

다른 사용자의 데이터에 URL 조작만으로 접근하는 취약점 — 프로필 조회 우회와 패치된 버전 실습

 준비 중

Broken Authentication

세션/비밀번호 관리 미흡으로 인한 인증 우회
모든 실습은 브라우저 안 시뮬레이션입니다 · 실제 서버/DB를 사용하지 않습니다
