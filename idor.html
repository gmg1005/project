IDOR 실습실 — 접근 통제 미흡 데모

IDOR(Insecure Direct Object Reference)는 사용자가 요청하는 객체 식별자(ID)의 권한을 서버가 제대로 검증하지 않을 때 발생하는 취약점입니다. 내 계정 번호를 살짝 바꿔서 다른 사람의 정보를 조회해보세요.

IDOR란 무엇인가?

웹 서비스는 보통 사용자마다 고유한 번호(ID)를 부여해 데이터를 관리합니다 (예: /api/user?id=1). 이때 서버가 "현재 로그인한 사용자가 이 데이터를 볼 수 있는 권한이 있는가?"를 검증하지 않고 파라미터 값만 믿고 그대로 데이터를 반환하면, 공격자가 ID 숫자를 임의로 바꾸어 다른 사용자의 민감한 개인정보를 탈취할 수 있습니다.

취약한 코드와 안전한 코드의 차이

취약한 코드 (Server)
// 파라미터 ID를 권한 검증 없이 바로 조회
$id = $_GET['id'];$query = "SELECT * FROM users WHERE id = $id";
$result = db_query($query);
안전한 코드 (Server)
// 세션의 내 ID와 요청된 ID가 일치하는지 검증
if ($_SESSION['user_id'] !=$_GET['id']) {
    die("접근 권한이 없습니다.");
